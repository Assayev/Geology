# Фирменный бланк CGC

Оригинал бланка клиента — `assets/CGC_letterhead_template.docx` (+ эталонный PDF `assets/CGC_letterhead_reference.pdf`). Любой документ «на бланке» строится **только от этого шаблона**, а не с нуля.

## Что в бланке (всё лежит в header1.xml шаблона — не трогать)
- Логотип CGC (image2.png) слева вверху; водяной знак CGC (image1.png), прозрачность 5 %, по центру страницы за текстом.
- Таблица 3 колонки, Arial 8 pt, разделители между колонками: RU / KZ / EN — адрес (г. Астана, пр. Кабанбай батыра, 17, Z05H0B4), тел. +7 (7172) 792570, info@caspiangeo.com.
- Страница A4, поля: верх 2 см, низ 2 см, лево 3 см, право 1.5 см (1134/1134/1701/850 twips), колонтитул 1.25 см. Тело документа начинается под шапкой автоматически.

## Как делать документ
```python
import sys; sys.path.insert(0, "<skill_dir>/scripts")
from cgc_doc import new_doc, para, table, save
doc = new_doc()                       # шаблон, пустое тело; Times New Roman 12
para(doc, "", after=40)               # отступ под блок шапки (как в примере)
para(doc, "Текст…", align="justify", first_indent_cm=1.25)
table(doc, [["№","Наименование"],["1","…"]], widths_cm=[1,9])
save(doc, "out.docx", pdf=True)       # docx + PDF рядом
```
Для сложного содержимого можно использовать python-docx напрямую поверх `new_doc()` — главное, чтобы шапка/секция остались из шаблона. Пример: `examples/sample_letter.docx|pdf`.

## Правила
1. Не менять header1.xml, картинки, `sectPr` (поля/размер страницы). `save()` сам возвращает шапку побайтно как в оригинале.
2. Шрифт тела не задан бланком; по умолчанию Times New Roman 12 pt (переопределяется `new_doc(font=, size=)`), если пользователь не указал иное.
3. Всегда после сборки: `python3 scripts/verify.py out.docx out.pdf` → должно быть `PASS`. И визуально посмотреть страницу 1 (PDF→PNG через `pymupdf`) и сравнить с эталоном.
4. PDF рендерится LibreOffice (нужны `libreoffice-writer`, `fonts-liberation`; если нет — `apt-get update && apt-get install -y libreoffice-writer fonts-liberation`). LibreOffice не умеет 5 % прозрачность и рисует разделители толще, поэтому `save(pdf=True)` подготавливает *временную копию* для рендера (водяной знак заранее выцвечен, линии 0.75 pt); сам .docx остаётся оригинальным. Arial в PDF заменяется на Liberation Sans (метрически идентичный).
5. Итоговый .docx — главный файл (в Word выглядит точно как оригинал); PDF — вспомогательный.
6. Если бланк нужен для другого формата (xlsx, pptx) — сказать пользователю, что бланк только Word/PDF, и уточнить.
