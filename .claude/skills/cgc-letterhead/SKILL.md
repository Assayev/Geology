# Фирменный бланк CGC

Основа — файл клиента `assets/CGC_letterhead_template.docx` (исправленная клиентом версия; первая версия — `assets/CGC_letterhead_v1_original.docx`, эталонный PDF шапки — `assets/CGC_letterhead_reference.pdf`). Любой документ «на бланке» строится **только от этого шаблона**, не с нуля и не через другой шаблон.

## Что в бланке (не менять)
- **Шапка (header1.xml):** логотип CGC слева, таблица из 3 колонок RU / KZ / EN (Arial 8 pt, чёрные вертикальные разделители): Астана, пр. Кабанбай батыра, 17, Z05H0B4; тел. +7 (7172) 792570; info@caspiangeo.com. Водяной знак CGC на 5 % по центру страницы за текстом.
- **Страница:** A4, поля верх/низ 2 см, лево 3 см, право 1,5 см, колонтитул 1,25 см. Текст начинается сразу под шапкой — отступов «под шапку» делать не надо.
- **Стиль Normal:** Times New Roman 12 pt, одинарный интервал, **интервал после абзаца 0** (расстояния делаются пустыми строками).

## Правила вёрстки (как в исправленном образце клиента)
1. Первая строка — исх. номер/дата: `Исх. № ____ от «__» ________ 2026 г.` (слева, сразу под шапкой).
2. Пустая строка ×3 → блок адресата: отступ слева 5812 twips (10,25 см), текст **по центру** внутри блока («Директору ТОО «…»», «Ф.И.О.»).
3. Пустая строка ×2 → обращение «Уважаемый …!» **по центру**. Тема письма («О …») в образце клиента отсутствует; добавлять только если пользователь просит — жирная, **по центру** (подтверждено клиентом).
4. Основной текст: **по ширине**, отступ первой строки 709 twips (1,25 см); между абзацами **одна пустая строка**; сразу после обращения без пустой строки.
5. Таблицы: стиль «Сетка таблицы» (Table Grid), отступ 704 twips, общая ширина 8647 twips, ставятся сразу под абзацем, шапка таблицы жирная.
6. После текста/таблицы 2 пустые строки → подпись **по центру**: `Директор` + пробелы + `____________ / Ф.И.О. /` (подтверждено клиентом, не менять на выравнивание по краям).
7. Для не-писем (отчёты, акты, ведомости) — те же шрифт, поля, стили и шапка; заголовки жирные, по центру, без «пробела после абзаца».

## Как собрать документ
Нужны `python-docx` (и `pillow` для PDF). Скрипты лежат в `scripts/`.
```python
import sys; sys.path.insert(0, "<папка_скилла>/scripts")
from cgc_doc import *
doc = new_doc()                                   # бланк с пустым телом
letter(doc, "Исх. № 12 от 29.09.2026 г.",
       ["Директору ТОО «X»", "Иванову И.И."], "Уважаемый Иван Иванович!",
       ["Абзац 1", "Абзац 2"],
       table_rows=[["№", "Наименование", "Ед.", "Кол-во"], ["1", "…", "…", "…"]],
       signer=("Директор", "Ф.И.О."))
save(doc, "out.docx", pdf=True)                   # .docx (+ .pdf, если есть LibreOffice)
```
Свободная вёрстка: `para(doc, text, align=, bold=, left=, first=)`, `blank(doc, n)`, `body_text(doc, text)`, `table(doc, rows, widths)`.
Пример результата: `examples/sample_letter.docx|pdf`.

## Обязательная проверка перед выдачей
`python3 scripts/verify.py out.docx [out.pdf]` → должно быть `PASS` (шапка, картинки, поля побайтно как в шаблоне; в PDF позиции блоков шапки как в эталоне). Затем посмотреть страницу 1 (PDF→PNG) и убедиться, что текст не заезжает на шапку.

## Если нет Python/скриптов (чат Claude без выполнения кода)
Работать с .docx как с zip: взять `assets/CGC_letterhead_template.docx`, заменить в `word/document.xml` всё между `<w:body>` и `<w:sectPr` на свой текст (абзацы `<w:p>`), **не трогая** `header1.xml`, `word/media/*`, `styles.xml`, `sectPr`, и собрать zip обратно (тот же порядок, `[Content_Types].xml` первым).

## Нюансы PDF
PDF рендерится LibreOffice (`libreoffice-writer`, `fonts-liberation`). Он не поддерживает 5 % прозрачность и рисует разделители толще, поэтому `save(pdf=True)` рендерит *временную копию* (водяной знак заранее выцвечен, линии 0,75 pt); сам .docx остаётся оригинальным. Arial подменяется метрически идентичным Liberation Sans. Главный файл — .docx (в Word выглядит точно как оригинал).
